Sound Board

Every sound in the Band Arcade, from shared/sounds.js. Upload a recording into shared/sounds/ with the file name shown (.m4a or .mp3), then press RELOAD ALL SOUNDS. This page always asks the server for the live files (it skips the browser's saved copies), so a file you just uploaded, replaced or deleted shows up right away; GitHub Pages can take a minute to publish an upload. Game pages keep their fast saved copies: after replacing sounds, add 1 to SOUNDS_VERSION at the top of shared/sounds.js so students get the new files. YOUR FILE = your recording plays. FALLBACK = the arcade's own built-in sound for that moment. MISSING FILE, USING GENERATED = a short generic beep until you add one. This page isn't linked from the arcade. The PLAY buttons play even when SOUND is off; the effects volume still applies.
