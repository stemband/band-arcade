# Lost Signal (`lost-signal/`)

- THE UI KIT: intro = `UI.intro` (theme `ls-theme`); the kit pause stops the tones (the transmission is marked interrupted and plays again, free, on RESUME), holds the echo slot clock (`echo.slotStart` restored) and keeps the game's own mic turn-taking (re-applied after RESUME); `Arcade.LostSignal.paused()`.
- Pitch-memory game (deep-space radio): the game plays a short melody (a transmission) with `Arcade.tones`, the student echoes it in order. Its pattern generator and echo flow are SHARED with Vanishing Ink (`shared/patterns.js`, `shared/echo.js`: PATTERNS / ECHO in [patterns-and-echo.md](../engine/patterns-and-echo.md)); Lost Signal keeps only its weights (`SIGNAL_GEN`), the tones, the first-note box, replays and the scope. LISTENS (pitch.js + mic-gate.js + sfx.js + tones.js + endless.js). NOTES × ORDER picks the note set (`ModePicker.sequence(...).pool`, one item per sounding pitch); Scale Order = stepwise transmissions only. Group-keyed progress (`picker.state.progressKey`, like Ghost Notes), `maxStars` 24. Snare: not allowed (needs pitch); bells play it.
- THE MIC TAKES TURNS (the Hard-rules exception, [CLAUDE.md](../../CLAUDE.md)): `mic(false)` = `Pitch.pauseListening(true)` + `Sfx.sync()` before every tone and every mic:false sound; `mic(true)` only after `tones done + RULES.listenAfterMs` and `lost-signal-your-turn` (+ 250 ms), with `ignoreCurrent()`. Menu music (`lost-signal-music`, built-in chiptune until uploaded) only on the level screens; `setMusic(null)` for play.
- Patterns: `levels.js` = `SIGNAL_LEVELS` (8: count, len, pool, leap (half steps: 2 step, 4 3rd, 7 5th, 12 octave), repeats, label, find, replays, noteMs, gapMs, story, nowWhat; `label: true` on all 8, `find: false` on all 8), `SIGNAL_RULES` (slotMs 6 s, listenAfterMs 400, base, replayCost, star rates, `register` [55, 79] = concert G3–G5), `SIGNAL_GEN` (move weights, recover after a skip, no two big skips in a row), `SIGNAL_ENDLESS`, `SIGNAL_ENDING`. Generated in SOUNDING pitch, played shifted by whole octaves as a block (`shiftFor`) into the register; answers match by pitch class (any octave). Never the same transmission twice in a row.
- Input: `Pitch.onAttack` (with its pc) fills the next slot; `onHeld` too when no attack was heard for that note within 700 ms (soft entries), so a long note fills ONE slot and a repeated note needs a new tongue. Slots fill right or wrong and move on; `slotMs` without a note = missed. THE FIRST NOTE IS ALWAYS NAMED (`#first`, aria-label "First note: …"): every level 1–8 and every Endless round, so the student always gets the starting pitch; levels get harder through length, skips, speed, repeats and fewer replays. A level with `label: false` would still work (static covers `#first`, aria-label "First note: hidden by static", the card says "first note hidden"). FIND THE SIGNAL (levels 5–6 used to hide the first note and make the student search for it, with `findCost`/`findReveal` and a "Show me" button) is RETIRED and its code removed: the `find` field stays in levels.js but the game ignores it; the `lost-signal-found` sound entry stays, unused. Points = `base` × right notes × (1 − `replayCost` × replays). REPLAY SIGNAL before the first note (`replays` per transmission, −`replayCost` each); "Hear it again" on the result (free). Result: `staffSVG` in written pitch: gold right, coral wrong + "you played D", coral missed in a dotted box. Stars from accuracy (70 / 85 / 100 % + no replays). The Source cleared = `SIGNAL_ENDING`. First visit: SIGNAL CHECK (`gameData('lost-signal').signalChecked`).
- DEEP SPACE SCAN (the ENDLESS card, shared/endless.js Top 5 per member + note set): the same pattern + one note per perfect round; a missed round costs a heart and replays the same pattern; the first note named every round (`labelRounds: Infinity`; a number N = named for the first N rounds, then static); faster every 5 rounds (`minNoteMs`); score = 100 per right note + 50 × length for a perfect round; GAME OVER = longest signal, score, rounds survived.
- Look: `--ls-*` tokens; the scope canvas (radar sweep + a ping per note + waveform; still under reduced motion; dpr ≤ 1.5, rAF only while something moves); static on the first-note box (only for `label: false`, none today) = slow low-contrast noise (2.5 steps/s). Cabinet: `shape: 'signal'`, `screen: 'signal'`, marquee scene `radio` (font GN Neon), 3D profile `signal` with a `dish` topper. `?demo`: Space = the note the game wants (`Pitch.demoTarget`), W = a wrong one, 1–5 = held first-five notes. `A.LostSignal.state()` for tests.
- Level copy (levels.js `story` / `nowWhat`): 5 Static Storm = the storm makes the signal faster and jumpier, the first note still gets through; 6 Nebula = 5 notes, skips up to a 5th; 7 Deep Space = no replays; 8 The Source = 6 notes, repeats. Every `nowWhat` from level 5 on says the first note is named. Test: `tests/lost-signal-first-note.spec.js` (every level and Endless rounds 1/4/10 name the first note, no FIND phase, card summaries, perfect-run score).
