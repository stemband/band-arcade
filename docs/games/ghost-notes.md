# Ghost Notes (`ghost-notes/`)

The old CLAUDE.md had no section of its own for Ghost Notes: it is the reference game the other docs point to. What exists about it is in:

- [adding-a-game.md](../engine/adding-a-game.md): a new game copies `ghost-notes/index.html`'s `<head>` version lines and shared script tags.
- [sound.md](../engine/sound.md): its note clock pauses while `Pitch.isSuppressed` (sound while listening).
- [notes-and-scales.md](../engine/notes-and-scales.md): it uses the MODE PICKER and the PROGRESS KEYS table (group-keyed progress).
- [page-flow.md](../engine/page-flow.md): its `fit` (not snare).
- `shared/games.js`: its entry (zones, `menuMusic`, `maxStars`, cabinet, marquee, background).

When you change Ghost Notes, write what you changed here.
