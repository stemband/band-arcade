# Vanishing Ink (`vanishing-ink/`)

- THE UI KIT: intro = `UI.intro` (theme `vi-theme`, the Ink Master as hero); the kit pause holds the study clock, the fade, the brush-in and the slot clock; `Arcade.VanishingInk.paused()`.
- Reading-memory game (Band Ninja world, the step after Ghost Notes): a short line of notes is brushed onto the Ink Master's parchment scroll, the ink FADES or VANISHES, the student plays the notes back in order from memory. LISTENS (pitch.js + mic-gate.js + sfx.js + patterns.js + echo.js + endless.js). NOTES × ORDER picks the note set (`A.patterns.noteSet`); patterns from `A.patterns.generate` with `INK_GEN`; Scale Order = stepwise only. Group-keyed progress (`picker.state.progressKey`, like Ghost Notes), `maxStars` 24, zones note-reading + ninja-dojo. Snare: not allowed. Answers match by concert pitch class (any octave).
- A ROUND (`nextRound`): `mic(true)` at once (listening, `ignoreCurrent`), phase `brush` (each note appears `RULES.brushMs` apart, WAAPI, `ink-brush` each; all at once under reduced motion) → `study` (the rAF game clock `R.t`, `studyMs`; the ink-drop timer; FADE: `setInk` lowers every note's opacity together over the last `fade` share, `ink-fade` once; the study clock never pauses for sounds) → `inkGone()` (VANISH: `puff()` + `ink-vanish`; `Pitch.ignoreCurrent()`, phase `echo`, `echo.start()`, `ink-your-turn`) → the ECHO FLOW (`slotMs` 6 s each, `pauseSuppressed`) → `finishRound()` (`mic(false)`, `Echo.drawResult` on the scroll: the ink comes back marked, "4 of 5 notes remembered. +pts"). While the ink shows (phases brush/study/reveal) NOTHING counts: any attack, held note or `onFrame` reading shows "READ, DON'T PLAY YET" (`#nope`, `R.warned`). The scroll's staff is `Echo.drawResult(… plain: true, idPrefix: 'ink')` so the results land in the same place; notes are `.ink-note` groups drawn in `--vi-ink`.
- REVEAL SCROLL: before the first note only (`echo.i === 0`), `L.reveals` per ROUND, `RULES.revealMs` of ink, −`revealCost` of that round's points; the slot clock restarts after it. Stars: `oneStar` 70 %, `twoStar` 85 %, 3 = 100 % and no reveals in the level. A star opens the next level; Invisible Master cleared = `INK_ENDING` (the Ink Master's last words).
- `levels.js` = `INK_LEVELS` (8: name, rounds, len, pool, leap (2 steps, 4 thirds, 5 mixed up to a 4th, 7 fifths, 12 all), repeats, study s, ink 'fade'|'vanish', fade share, reveals, say (the Ink Master's intro line), nowWhat), `INK_ENDING`, `INK_RULES`, `INK_GEN`, `INK_ENDLESS`.
- ENDLESS SCROLL (the ENDLESS card, shared/endless.js Top 5 per member + note set): starts with `startLen` 2, a perfect round adds one note to the SAME pattern (`A.patterns.next`); study = max(`minStudy` + `minPerNote` × n, (`study` + `perNote` × n) × `shrink`^(round − 1)); FADE for `fadeRounds` 5, then VANISH; 3 lives (any wrong/missed note costs one and the same scroll returns); no reveals; score 100 per right note + 50 × length for a perfect round; GAME OVER = longest scroll, score, rounds survived (`ink-game-over`, `ink-high-score`).
- THE INK MASTER (`inkMasterSVG(mood 'calm'|'happy')` in game.js, `.im-*` in style.css, `--vi-master*` tokens): an original friendly old octopus calligrapher in a black-belt headband, white brows and mustache, a brush in one arm. Keep him kind and original (no franchise ninjas).
- Sounds (screen `vanishing-ink`, every one unpitched noise, `gen` fallbacks): `vanishing-ink-music` (loop, FILE ONLY: no built-in chiptune; menus only), during play (mic: true, short): `ink-brush`, `ink-fade`, `ink-vanish`, `ink-your-turn`, `ink-note-correct`, `ink-note-wrong`, `ink-reveal-scroll`; mic: false: `ink-round-complete`, `ink-level-clear`, `ink-life-lost`, `ink-game-over`, `ink-high-score` (level results also use the shared `level-failed`, `star-earned`, `new-high-score`).
- Look: `--vi-*` tokens (parchment, rods, ink, seal, the Ink Master), the Dojo Duel night (`--dd-*` lanterns + floor), titles in `GN Brush`. The staff is large (up to 40vh; sized for each scroll's own notes, results in the same size), dark ink on light parchment, thicker stems/lines. Reduced motion: no brush-in animation, no puffs, no lantern sway (the fade itself stays: it's the game). Cabinet: `shape: 'ink'` (scroll rods beside the marquee, an ink splash, a fading note, a brush), `screen: 'ink'`, marquee scene `ink` (font GN Brush), 3D profile `ink` with a `scroll` topper. `?demo`: Space = the note the game wants (during study: the first note, to test the warning), W = a wrong one, 1–5 = held first-five notes. `A.VanishingInk.state()` / `.echo()` for tests.
