# Note Storm (`note-storm/`)

- THE UI KIT (every game in docs/games/ uses it the same way, see [ui-kit.md](../engine/ui-kit.md)): results = `A.UI.results.show`, the pause = `A.UI.pause` (active only while a level/round/match runs; the in-level "Quit"/"Leave" buttons are gone: pause → BACK TO … asks first), intros = `A.UI.intro`, option toggles = `.ui-seg`. Note Storm's pause stops the loop (Tempo's `.is-paused`); BACK TO LEVELS in Endless drops the run ("End this run?"), as Quit run did.
- Notes march left along the staff toward Tempo (the robot); play a note to blast it; one reaching Tempo costs a life (3). LISTENS (pitch.js). NOTES × ORDER like every note-reading game.
- SEVERAL NOTES AT ONCE: a played pitch blasts the note CLOSEST TO TEMPO with that pitch (`G.notes.find`, oldest first); no match on the staff = a wrong note. One held note = one blast (onHeld fires once per note): the same pitch twice needs a fresh attack; the first multi-note level shows "Same note twice? Tongue it again!" once per device (`gameData('note-storm').sameTip`). New notes wait for `maxOn` and `RULES.gapUnits` of room, so they never overlap; the staff gets wider (a smaller drawing on phones) so `maxOn` notes fit.
- THE STORM NEVER STOPS: notes, spawning and the clock keep going through shots, sounds and the mic's mute; only the pause button, a hidden tab and the start/results screens stop it. The first note waits for the `level-start` sound. `RULES.muteMs` = `Sfx.muteMax`.
- `levels.js` = `STORM_LEVELS` (8 levels, one commented table: count, pool, march (s to reach Tempo; keep ≥ 2.5), every (average s between notes; keep ≥ 0.7), gust (runs of quick then slow notes, same average), maxOn 1–5, names) + `STORM_RULES` + `STORM_ENDLESS`. Stars saved by level number: keep 8 levels. `A.Storm.state()` for tests.
- ENDLESS (`G.endless`, the ∞ card): `G.L` is recomputed every frame from SPEED (1 = Level 1's pace): march = march1 ÷ SPEED (never under `minMarch` 2.2 s), every = every ÷ SPEED (never under `minEvery`), maxOn from `more` (5 at about Level 8's speed); past the march floor the rising SPEED only brings notes closer together. Notes come in 24-note chunks from `ModePicker.sequence` (the smaller pool until `smallPoolUntil`; a chunk never starts on the last note's pitch). The staff is laid out for 5 notes from the start (`G.roomOn`). A note reaching Tempo = a heart (`endless-life-lost`); a wrong note only breaks the combo. The HUD shows Speed, Combo, hearts, Score.
