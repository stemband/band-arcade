# Neon Face-Off (`neon-face-off/`)

- THE UI KIT: the kit pause freezes the whole match (`later()` is a pausable clock: countdown beats, CPU reactions, the serve, celebrations; the puck); BACK TO SETUP; results: the winner's color (`theme: 'nfo-res w-p1|w-p2'`), stars vs CPU only, REMATCH / MATCH SETUP (+ NEXT RIVAL). `A.FaceOff.state()` adds `frozen`, `puckT0`, `timers`.
- Two-player air hockey played with instruments, one device, one microphone, turn-based. Player 1 cyan, Player 2 magenta (`--pink`). Player 2 is `store.opponent`: another member, or `'cpu'` (the ladder). Humans are shown as avatars with their names (`p.name`; `p.inst` = the instrument) and a 1P/2P marker (`.pmark`): Player 1 = the device's avatar, a human Player 2 = the GUEST avatar (`Avatar.guest()`, SURPRISE ME on the setup screen re-rolls it; it never replaces the device's own). CPU rivals keep their recolored instrument portraits. Landscape: P1 left, P2 right; portrait: P2 on top (its panel rotated 180° to face them), P1 at the bottom. The table is a canvas (requestAnimationFrame, cheap shadows/gradients, dpr ≤ 1.5); reduced motion = no trail, no shake, no pulse.
- MICROPHONE: only the active player's target counts. Each turn: `Pitch.setInstrument(group)`, their range (`setRange(member range)` for scale/chromatic pools, `null` for First 5), `ignoreCurrent()` (the other player's note still ringing never counts: pitch.js STALE SOUND); the wrong-note line "That's D. Look again!" = `p.seq.name(pc)` for the ACTIVE player (their written note, the key signature's spelling in a scale; tests/faceoff-notes.spec.js plays real tones through a tone microphone); a target never shares its concert pitch class with the note the other player just played. HIT → NOTE: the receiver's note appears AT ONCE after a hit (`.side.waiting`: the note panel dimmed, status "…"); the in-rally sounds (puck-hit-soft/-hard, puck-smash, your-turn) mute the detector at most `RULES.maxHitSuppressMs` (300 ms, echo included: `Sfx.event(name, {muteCap})`); the game loop's `goLiveIfReady` waits for the REAL end of the mute (`Pitch.isSuppressed`, never a fixed guess), then lights the panel (`.side.live`, one short glow), starts the reaction clock (`M.noteAt`) AND the puck's travel (`M.puck.hold` until then; crossing time = max(base × power factor, the receiver's window), so a long sound never shortens a window); the puck + reaction clock also freeze during any later mute. The CPU plays silently (it goes live the same way).
- COUNTDOWNS (`shared/countdown.js`, voicePrefix 'faceoff', `RULES.countdown`): CLASSIC 3-2-1-GO before the first serve (after the one-time smash tip on a device's first match, `gameData.smashTip`, `RULES.tipMs`), READY-GO before the serve after every point (after `RULES.celebrateMs` 1300 of goal celebration: about 2.2 s in all with a "Go!" file under 0.45 s), CLASSIC instead when either player is one point from winning; never between rally hits. From the goal to the "GO!" the mic is PAUSED (`Pitch.pauseListening`: nothing counts, no note shows, the faceoff-* voices are mic: false); the serve note appears and the mic listens as the "GO!" voice ends. The beat is drawn big on the rink (`#count`, `showCount`; kind classes `k-ready`/`k-go`), twice in portrait (the top one turned for Player 2). The setup screen shows the smash tip (`.smash-tip`). `A.FaceOff.state()` = `{state ('count'|'serve'|'travel'|'celebrate'|'over'), active, live, liveWait, countStyle, countLog, hold, T, score, paused, suppressedFor}` for tests.
- Notes: `Arcade.buildSequence` per player (their own member, NOTES × ORDER from their own picker, Rookie = the smaller level-1 pool). Strike power from reaction (note shown → note registered): `FACEOFF_RULES.power` (SMASH! / POWER / GOOD / WEAK) × a rally base that shrinks each return; a shot never gives the receiver less than their difficulty's window (+ `suppressMs`). A timeout = the other player scores; `serve: 'loser'` (the player scored on serves) or `'alternate'`. Wrong note: "That's D" in the player's written pitch, time keeps running.
- `levels.js`: `FACEOFF_RIVALS` (8 CPU rivals: name, color, plays (an instrument id for its portrait), reaction [min, max] s, accuracy), `FACEOFF_DIFFICULTY` (Rookie 4 s, Pro 2.5 s, All-Star 1.5 s), `FACEOFF_RULES`. Stars vs CPU: win 1, win by 4+ 2, shutout 3; saved `setLevel('neon-face-off', Player 1's member id, rival, {stars, best})` (`byMember`). Two-player matches: no stars; `store.gameData('neon-face-off')` = `{settings: {p1: {diff}, p2: {diff}, points, rival}, h2h: {'<p1 member>><p2 member>': {p1, p2}}, cpuWins}` (cpuWins: every win over the CPU, for the Air Rink background).
- `?demo`: every rival unlocked; hold Space = the active player's note (press later = slower), W = a wrong note.
