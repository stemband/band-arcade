# Instruments, notes and scales

- `Arcade.INSTRUMENTS`, `Arcade.currentInstrument()`. Each instrument (player group) has `notes` (written), `targetPc` (concert pitch classes), `writtenName(pc)`, `clef`, `t` (transposition), `concertLabel`, `shortName`, and `members`. Never change a group's `id`, first five notes or `t`: saved stars and links depend on them (the flute group's name lost "Colored Tone Bells" when that member was removed).
- UNPITCHED PLAYERS: the Snare Drum is group `snare` / member `snare` (`pitched: false`, no notes, no chromatic range; `inst.pitched` is true for every other group). Only games with `unpitched: true` in games.js take it (Showtime Malfunction, the Note Checker's ARTICULATION mode); `requireInstrument` sends it to Select Player with `&need=pitched` everywhere else ("Snare drummers: try Showtime Malfunction! …", `A.SNARE_MSG`); Select Player dims its tile there (`.no-play`) and refuses it (incl. Face-Off's Player 2 and CONTINUE AS); the floor shows a link to Showtime Malfunction instead of a hi-score. Fixed-player games (Chime Heist, Ancient Ninja Scrolls) are unaffected. Never call scales/sequences for it.
- Members (`inst.members`): the real instruments in a group, `{id, name, short (tile/chip label), family ('woodwind'|'brass'|'percussion'), chromatic: [lowest, highest written], sounds, pitched}`; `Arcade.PLAYERS` = the 16 member ids in Select Player order (woodwinds, then brass, bells, snare), `Arcade.memberById(id)`, `Arcade.groupsOf(id)`. `sounds` = exact semitones the instrument sounds BELOW written pitch (negative = higher; bells −24, tenor sax 14), octave included, always ≡ `t` mod 12. Ranges come from the **GMEA All-State Middle School Chromatic Scale sheets**; if GMEA changes a sheet, update `MEMBERS` in `instruments.js` (not a game). Helpers: `Arcade.getMember(inst, id)`, `Arcade.chromaticScale(member, {down})` (written notes with `midi` and `sounding`; sharps going up like the GMEA sheets, flats going down, end notes keep their given spelling), `Arcade.music.spell(midi, flats)`.

- Scales (`shared/scales.js`, every game + the Note Checker + the home page; + THE AUDITION table for Scale Trainer, see its section in [scale-trainer.md](../games/scale-trainer.md)): `Arcade.Scales.LIST` (`Bb`, `Eb`, `F`, `Ab`, `chrom`), `Scales.build(member, id)` → `{name, label ('Concert E♭ (your F Major)'), key, sig {type, count}, up, notes (up then down)}`, each note `{letter, acc, oct, midi (written), sounding, pc, show}` where `show` is how to draw it under the key signature. Written scales are transposed with the member's `sounds` and spelled in the written key (never mixed sharps/flats). The **`START` table** at the top of scales.js holds the written starting note for every member × scale; it should match the GMEA scale sheets, and a wrong-key entry falls back to the rule (B♭ = the first-five tonic; others = the tonic nearest that whose octave fits the GMEA range). `Scales.sequence(scale, count)` repeats the scale to fill a level; `Scales.progressKey(gameId, id)` = `'<gameId>:scale-<id>'`.

- NOTE SEQUENCES (`shared/sequences.js`, on top of scales.js): THE way a note-reading game gets its notes. `Arcade.buildSequence({member, group, notes, order, level, count, pool})` -> `{items, pool, fit, sig, scale, name(pc), small}`; each item `{n (written note, key-correct spelling: answers use it), show (how to draw it), label, midi (written), sounding, pc}`. NOTES: `'first5'` (the group's first five; Horn's Starting notes pick the group) | `'Bb'|'Eb'|'F'|'Ab'` (the member's one-octave written scale from scales.js, 8 notes, same octave as scale mode) | `'chrom'` (the member's whole GMEA range). ORDER: `'random'` (bag shuffle: every pool note before any repeats, never the same pitch twice in a row; the level's `pool` below 5, i.e. level 1, uses the smaller pool: first three / the scale's first five / one octave from the first-five tonic; chromatic black keys spelled ♯ or ♭ at random) | `'order'` (up then down, then again from the second note; first5 = the five up and down, chrom = up in sharps, down in flats). Scale pools draw the key signature in both orders (`sig`, `show`); first5 and chrom draw accidentals, no key signature. Also `Arcade.progressKey(gameId, notes, order)`, `Arcade.progressKeys(gameId)` (all 12), `Arcade.NOTE_CHOICES`, `Arcade.ORDER_CHOICES`.
- MODE PICKER (`shared/mode-picker.js`, styles `.mp*` in theme.css): `Arcade.ModePicker.mount(el, {gameId, levels, onChange, group?, member?})` draws NOTES (six buttons, each with its stars for the chosen ORDER out of the game's `maxStars` from games.js) and ORDER (Random | Scale Order) plus a line explaining the choice; remembered per game (`store.noteMode`/`setNoteMode`; `memory: key` remembers it elsewhere, e.g. Neon Face-Off's `'neon-face-off:p1'`/`':p2'`; `stars: false` hides the star totals; `keySuffix: () => ':extra'` reads stars from the keys + that suffix, `max` overrides the per-combination maximum; `picker.refresh()` redraws). `picker.state` = `{notes, order, member, group, scale, progressKey, label}`. Helpers: `ModePicker.sequence(state, L, lv)` (buildSequence for a level row), `levelText(state, L, lv, extraParts)` (the game's own blurb for First 5 + Random, else what the level plays + the game's parts), `hubCard(state)`, `useRange(state)`, `demoSpace(fn)`. Used by Ghost Notes, Note Storm, Note Ninja, Chime Heist (group/member = the bells) and Neon Face-Off (one per player, no stars); NOT by Button Masher, Ancient Ninja Scrolls or the Note Checker.
- PROGRESS KEYS for note-reading games (never rename; `KEY_OVERRIDES` in sequences.js keeps a game's older keys):

| NOTES | ORDER | Progress key | Notes |
|---|---|---|---|
| First 5 | Random | `<game>` | the original key: every star from before scales still counts here |
| First 5 | Scale Order | `<game>:order-first5` | new |
| Concert B♭ / E♭ / F / A♭ | Scale Order | `<game>:scale-Bb` … `:scale-Ab` | the original SCALES keys |
| Chromatic | Scale Order | `<game>:scale-chrom` (Chime Heist: `chime-heist:chromatic`) | the original keys |
| Concert B♭ / E♭ / F / A♭ | Random | `<game>:random-Bb` … `:random-Ab` | new |
| Chromatic | Random | `<game>:random-chromatic` (Chime Heist: `chime-heist:full`, its old FULL RANGE) | new (Chime Heist: kept) |

## Staff drawing

- `Arcade.staffSVG(clef, items, {fit, label, width, captions, keySig, extra})` (items may set `whole`, `stemUp`, `stemTo`: Scale Trainer's rhythm picture; `extra` = SVG drawn last) (key signatures in the standard positions, any count, treble or bass; start notes `Arcade.keySigWidth(sig)` further right; `n.natural` draws ♮), `Arcade.noteGlyph(clef, {n, x, caption}, capY)` (one note, for games that move notes on their own layer), `Arcade.noteY(clef, n)`, `Arcade.fiveNoteStaff(inst, colorFor)`, `Arcade.colorNote(id, color)`, `Arcade.ghostSVG(text, cls)`, `Arcade.ninjaSVG({belt, cls, label})` (the Note Ninja mascot; colors resolved from tokens so it also works as a canvas image), `Arcade.starStr(n)`, `Arcade.mountTopbar(inst, extraHTML, gameId, {fixed})`, `Arcade.symbolSVG(id, label)` / `Arcade.symbolName(id)` / `Arcade.SYMBOL_IDS` (music symbols on a short staff: treble-clef, bass-clef, fermata, repeat, measure-repeat, accent).
