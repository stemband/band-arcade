# The Band Ninja connection and shared pieces

- THE BAND NINJA CONNECTION (optional; `shared/bandninja.js`, loaded right after ui.js by every page; README "Band Ninja connection"): the arcade stays anonymous (sends nothing, stores nothing off the device). LINK SETTINGS `?inst=` (`INSTRUMENT_ALIASES` → `store.setPlayer`; unknown = ignored; the floor's `?game=` Select Player is skipped via `BandNinja.skipSelect()` in arcade.js), `?belt=` (Note Ninja) / `?rank=` (Ancient Ninja Scrolls): `BandNinja.levelWish(gameId)`, read ONCE by level-select.js at the screen's first appearance (the belt if open, else the highest open one + `.ls-bn` line); all three are applied once and removed from the address AND `A.params`. BELT REWARD CODES: `beltUnlockCode(belt)` is the portal's exact Apps Script algorithm (`ARCADE_CODE_SALT` must match the portal's; `selfTest()` in ?demo checks `EXPECTED`); `redeem(text)` (10 tries a minute, sessionStorage) saves `gameData('bandninja').belts` (in the Backup Code); Arcade Quest's Token Booth "Enter a code" = `Q.talk.beltCode()`, then `Skins.catchUp(member, {only: keys})`. OFFICIAL BAND NINJA GEAR = parts with `official: true` + `unlock: {bandninja: belt}` (avatar-parts.js end: the `belt` field `P.BN_BELTS`, drawn by avatar.js `beltLayer` with Z/z/Y; plates `bn-*`; top `bngi`; effect `bndiamond`; bg `bndojo` = bg-scenes `diamond-dojo`; colors `--bn-*` in theme.css): only a code opens it (never UNLOCK rules, stars or the shop); Create Your Player shows it only on its BAND NINJA tab, which appears once a code opened something (or ?unlockall); the Locker shows it only once earned. THE AVATAR CODE (`shared/avatar-code.js`, after avatar.js on every avatar page): `Arcade.avatarCode.encode/decode/valid/forDevice/share/load`; "BA1-" + base64url, a 12-bit check, then each TABLE field as an index (0 = default); TABLE is the format: APPEND only (new ids at the end of their list, new fields at the end); a new part must be added there (?demo warns). SHARE TO BAND NINJA in the creator + the badge menu; LOAD AVATAR CODE in the creator (locked items fall back, with a note). THE AVATAR CARD (`avatar-card/index.html?code&frame&still&name`): only avatar-parts/names, avatar.js, avatar-code, bg-scenes, avatar-bg, avatar-fx (no storage.js: no reads or writes, no unlock checks), `Arcade.avatarStill` (still=1) stops the animation loop, `color-scheme: normal` so it's see-through in any iframe; never add frame-busting or anything that blocks embedding.

## Belts and the Band Ninja shared pieces

- Belts (`shared/belts.js`): `Arcade.BELTS` = the 10 Band Ninja belts `{rank, name, color, sparkle}`, `Arcade.belt(rankOrName)`. The only place belt names/colors live; Note Ninja's levels.js matches by `name`, Ancient Ninja Scrolls uses ranks 3–10.
- BAND NINJA SHARED PIECES (ui.js + answer-pad.js): `Arcade.senseiSVG(mood 'calm'|'happy'|'hmm'|'present'|'ready'|'strike', belt)` = THE Sensei (Ancient Ninja Scrolls, Dojo Duel, Note Ninja: 'ready' = a wooden practice sword (bokken, `--sensei-bokken`) held calmly, 'strike' = mid-swing toward your left; `.ss-*` styles in theme.css); `Arcade.staffGuides(clef, x, alpha)` = the faint letter names after the clef (Note Ninja's belts, Dojo Duel); `Arcade.AnswerPad.mount(el, {accs, relabel, cls, onAnswer(letter, acc, ev)})` (shared/answer-pad.js, `.apad*` in theme.css) = Note Ninja's answer layout (♭ ♮ ♯ as a one-shot Shift, then A–G) as a component: answers on `pointerdown` (every finger its own pointer, so two pads work at once), `setAcc/press/set/lock/mark`. Note Ninja still has its own pad markup (same layout); new games use AnswerPad.
