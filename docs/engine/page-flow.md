THE ROTATION (so the plan doesn't repeat every week): a skill's `games` (the games that really practice it) TAKE TURNS WEEK BY WEEK; its `fallback` is ONLY for an instrument that can play none of them; `play` takes turns DAY BY DAY unless something is assigned; both count from `rotationStart` (a Monday, '2026-08-03'; change it to restart the cycle, e.g. a new semester). ## Links and the instrument check

- Links: `Arcade.link(path)` keeps the query string. `Arcade.linkTo(path, {game})` keeps `?demo` but sets or drops `?game=` (use it for links between pages). `Arcade.playerLink(gameId, root)`, `Arcade.homeLink(gameId, root)`; `root` is `'../'` from a game folder (the default) or `''` from the site root.

- `Arcade.requireInstrument(gameId)`: the saved instrument, or redirect to Select Player (returns null).
