# Endless mode

- ENDLESS MODE (`shared/endless.js`, loaded after sfx.js by Note Storm, Note Ninja, Lost Signal, Vanishing Ink, Keys to the City, Rhythm Dojo, Blocktave and Showtime Malfunction (THE ENCORE)): `Arcade.Endless` = `speed(C, t)` (C.start + (C.max − C.start)(1 − e^(−t/C.k)) + C.creep·t), `mult(combo)` (×2 at 10, ×3 at 25, ×4 at 50: `COMBO`), `instKey(inst, member)` (the member; Horn adds its group), `setKey(pickerState)` (`'<notes>-<order>'`), `top()`, `tile(el, {gameId, instKey, setKey, label, blurb, onPlay})` (the ∞ card under the levels, always open, with the Top 5), `gameOver({…, run: {score, notes, speed, combo}, onAgain, onBack, backLabel})` (the GAME OVER panel: saves, Top 5 with this run highlighted, `endless-game-over` + `endless-high-score` for a new #1; calls `Skins.announce`), `hearts()`, `flash(el, text)`, a game may pass `title` to `tile` and `title`, `kicker`, `againLabel` (the Play again button), `onShow(panel)` (the results kit's hook: Showtime Malfunction's band), `run.stats` ([[label, value]…] instead of the four standard boxes) and `sounds` ({over, top}) to `gameOver` (Lost Signal's Deep Space Scan) ("SPEED UP!": one gentle fade, never a strobe), `playerName()` (the avatar's name, else "Player"). Scores live in `store.endless` (`endlessTop(game, instKey, setKey)` / `addEndless(…)` keeps the best 5 `{score, name, date, notes, speed, combo}`), NEVER in `games`: no stars, no maxStars, no unlocks; the Arcade Backup Code carries them (it saves the whole store; the Quest code does not). Each entry also keeps the player's name `plate`, drawn in the Top 5. `?demo` runs never save ("Demo run — score not saved"); `Endless.saveInDemo = true` only while testing. Each game's numbers are one commented block in its levels.js (`STORM_ENDLESS`, `NINJA_ENDLESS`, `SHOWTIME_ENDLESS`: THE ENCORE in [showtime-malfunction.md](../games/showtime-malfunction.md)). Endless never pauses for a sound. Sounds (screen `endless`): `endless-start`, `speed-up` (during play), `endless-life-lost` (during play), `endless-game-over`, `endless-high-score`, each falling back to the older sound.
