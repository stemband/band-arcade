# The site version, the app and the play session

## THE APP (moved from the hard rules)

- **THE APP (installable, offline; `manifest.webmanifest`, `sw.js`, `shared/app.js`, `offline.html`, icons in `shared/app/` from `tools/app-icon.html`).** `checkVersion` writes every page's app tags (manifest link, apple-touch-icon, apple-mobile-web-app-* with a black-translucent status bar) and loads `shared/app.js` (`A.ROOT` = the site root from version.js's own address), so a new page needs only the three version lines + its own `theme-color`; `<meta name="arcade-app" content="off">` above them = no app.js (the avatar card, shown inside other sites). `A.v(url)` uses `A.pageVersion` (the page's own checkVersion value), so a kept old page never loads new files. THE SERVICE WORKER (`sw.js`, root, registered by app.js ONLY when VERSION isn't 'dev'; a leftover one is unregistered in dev): one cache per version `band-arcade-<version>`; the deploy (stamp-version.py) writes VERSION + `FILES` (every served file: a content fingerprint + 'p' stored at install: html/js/css/woff2/manifest/icons, or 'u' on first use: sounds, pictures); an install COPIES unchanged files from the older cache, downloads the rest; activate deletes older caches + `clients.claim()`. Pages (navigations) and version.js: network first with `cache: 'no-cache'`, the stored copy only when the network fails, else `offline.html` ("You're offline. Games you've played before still work!"). Everything else: cache first; `?v=<another version>` = network only, never stored (no mixed versions); requests with cache reload/no-cache/no-store or a Range header, other sites (THE LEADERBOARD) and non-GET are never touched. UPDATES (app.js): checked on load, when the page comes back on screen and every 30 min; a waiting worker whose version = this page's is activated silently; an older open page gets the banner `.app-update` "New version ready — tap to update" (hidden `html.in-play`; the tap = skip-waiting + reload); ignored = applied at the next open. INSTALL: `A.App.installButton(el)` (the floor's sound panel) only with `Arcade.TEACHER.SHOW_INSTALL_PROMPT` (teacher-settings.js, false until the final address), `beforeinstallprompt` is always held for it; iPad = the steps with pictures. BRING YOUR PROGRESS: the app's first launch (standalone + nothing in localStorage when app.js runs: `bandarcade.app-welcome` 'ask' → 'done', outside the Backup Code) on the floor, after PRESS START and before pick mode (`A.App.welcome(then)` in arcade.js): paste a Backup Code or Start fresh. `A.App.micHelp()` adds "open Band Arcade in Safari instead" to mic-gate's errors in the app. SAFE AREAS: `.wrap`, `.overlay` and every full-screen layout pad with `env(safe-area-inset-*)`. `?standalone` pretends to be the app (tests); `A.App.state()`. Tests: tests/app.spec.js (stamps two copies with `testv1`/`testv2`).

## THE PLAY SESSION

- THE PLAY SESSION (`Arcade.session`, shared/version.js: `has(k)`, `mark(k)`, `reset()`): once-per-session flags (the mic reminder `'mic-reminder'`, Music Highway's `'mh-calibrated-speaker'` / `'-headphones'`). A session = from opening the arcade until the tab is closed or a page is RELOADED: the flags live in memory and are handed to the next page of the same tab through `window.name` (never localStorage/sessionStorage); a reload (navigation type 'reload') starts a new one. Tests: tests/play-session.spec.js.
