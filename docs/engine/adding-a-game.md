# Adding a game

Make a new folder with `index.html` (the same `<head>` version lines and shared script tags as `ghost-notes/index.html`, including `games.js`, `scales.js`, `sequences.js` and `mode-picker.js`), `style.css` and `game.js`. Start `game.js` with `requireInstrument` + `mountTopbar(inst, '', GAME_ID)`. Load `portraits.js` + `skins.js` + `avatar-parts.js` + `avatar-names.js` + `avatar.js` + `games.js` + `sounds.js` + `sfx.js`, and call `A.Skins.announce($('results').querySelector('.panel'))` whenever the results screen shows (it also puts the player's avatar and name at the top). Show the PLAYER with `Arcade.avatarHTML({size, member})`, an INSTRUMENT with `portraitHTML`. A note-reading game gets its notes ONLY from `sequences.js` and its mode UI ONLY from `mode-picker.js`: mount `Arcade.ModePicker` on the level screen, build each level with `ModePicker.sequence(picker.state, L, lv)`, draw items' `show` with the result's `sig` and `fit`, check answers against `n` (or `pc`/`sounding` for the mic), save with `picker.state.progressKey`, and set `noteModes: true` in games.js. Never write a shuffle or scale loop in a game. First 5 + Random must behave exactly like the game always has (levels.js `pool: 3` on level 1). MENU MUSIC: give it `menuMusic: '<id>-menu'` in games.js + a loop entry in sounds.js (screen = its id) and call `A.Sfx.gameMenuMusic(GAME_ID)` on every menu screen, `(GAME_ID, false)` as a level starts, `(GAME_ID, true, {afterEffects: true})` when results show. Add it to `shared/games.js` (`maxStars` = levels × 3, or 0; `unpitched: true` only if it works for the Snare Drum; its `zones` and, if it doesn't suit every instrument, a `fit`: that's all the lobby needs) with a main `color` (`'pink'|'cyan'|'yellow'`), a `cabinet` entry and a `marquee` entry (its lit sign's scene: see MARQUEES in [backgrounds-cabinets-marquees.md](backgrounds-cabinets-marquees.md)). Reuse `theme.css` components (`.stage`, `.hear`, `.overlay/.panel`, `.btn-*`). Its first screen uses the LEVEL SELECT PATTERN: load `level-select.js`, call `A.LevelSelect.show(...)` wherever the level cards are drawn (picker + the `.ls-notes` staff first, then the cards, extras below) and `A.LevelSelect.played(lv - 1)` at the top of the level's start function; keep the cards' own click handlers (START runs them).
