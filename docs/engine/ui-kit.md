# The UI kit

- THE UI KIT (`shared/ui-kit.js` = `Arcade.UI` + `shared/ui-kit.css`; docs/STYLE.md = when to use what; `docs/gallery.html` = every piece and every game's level select / pause / settings / results side by side, pictures from `GALLERY=1` test runs): loaded on EVERY page by shared/version.js (checkVersion writes the two tags, the CSS BEFORE the page's own stylesheets so a game re-themes a piece in its style.css), inert until called. BUTTONS `.btn` + `.btn-primary` (yellow, the ONE main action) / `.btn-secondary` (outlined) / `.btn-danger` (red outline: leaving, starting over) / `.btn-small` (44 px) / `.btn-big` (60 px) (the old btn-gold/btn-ghost names are gone); OPTION TOGGLES `.ui-seg` (buttons with aria-pressed; `--seg-on` recolors); `.ui-switch`; HEADINGS `.game-title` (the kit sets size, the game its font/colors), `.ui-title`, `.ui-section` (THE GOLD SECTION HEADING: ① SELECT YOUR NOTES / ② SELECT YOUR LEVEL / UNLOCKED!), `.ui-kicker`, `.ui-label`, `.ui-howto` (the hub's how-to line); `.ui-tiles`/`.ui-tile` (stat tiles); `.ui-msg` (+ `.err` `.empty` `.loading`); `.ui-spin` (the same spinner in a button whose feature is still loading: `Arcade.need` adds it). PAUSE `UI.pause.mount({onPause(reason), onResume, onRestart, onLevels, levelsLabel, restartLabel, extras: [{label, onClick, id}], info: () => [[k, v]], note, confirmLeave, leaveText, canPause, pauseOnBlur, place, theme})` → `{setActive(on), pause(), resume(), paused, active, set(o)}`: ONE per page; `setActive(true)` when a level/round/match starts, `false` on every menu; the PAUSE button (`#uiPauseBtn`, ≥ 48 px) sits where "← Arcade" is (measured from `#topbar .brand`, else the top-left corner; `html.ui-in-level` hides that link; `place: el` = inside an element instead: Dojo Duel's center strip), Esc/P, a hidden tab/pagehide (and `pauseOnBlur`) pause; the menu `#uiPause` = RESUME · RESTART · SETTINGS · extras · BACK TO LEVELS (red; `UI.confirm` first when `confirmLeave()`, default true) · BACK TO ARCADE GAMES (`#uiPauseArcade`, `.btn-secondary`, in EVERY game: `arcade: false` hides it, `onArcade()` = the game's own clean-up; the same `confirmLeave` question first, then `Pitch.stop()` (the microphone off for good), `Sfx.hush()` and `playThenGo('ui-back', …)` to the floor's ALL GAMES view turned to this game (`A.homeLink(A.pageGame)` with sessionStorage `bandarcade.from` = `{view: 'all'}`; `A.pageGame` is set by mountTopbar); Dojo Duel's old EXIT is gone: the kit's button replaces it); while paused `Pitch.pauseListening(true)` (the previous state restored on resume, then only a new note counts). RESULTS `UI.results.show({gameId, theme, wide, hero, stars (0–3 | null), kicker, title, msg, tiles, best, newBest, newBestText, extra (html|el), next, retry, levels, more, actsFirst, announce, onShow})` = THE results screen (`#results`, buttons `#resNext` / `#resRetry` / `#resLevels` in that order, LAST, after the game's `extra`; `actsFirst: true` = the buttons row (`.ui-res-acts.ui-res-first`; the overlay gets `.ui-acts-first`) right after the tiles / best line, ABOVE the extra part, and an UNLOCKED! card goes under the buttons (only Sustain Speedway; tests/results-acts-first.spec.js); the first shown of NEXT / TRY AGAIN is yellow and focused; stars pop in one by one (`.ui-stars.go`), the NEW BEST ribbon settles in; it calls `Skins.announce` itself (`announce: false` to skip, or `{members, member}`) and deactivates the pause); `UI.results.hide()`, `.shown`, `render(el, o)` = the same screen inside an element (Dojo Duel's halves). Labels: `Next <noun>`, `Try again` (two-player: `Rematch`), `<Nouns>`. Endless GAME OVER (shared/endless.js) is this screen with `theme: 'ed-over'`, no stars, the Top 5 as its extra. SETTINGS `UI.settings.open({lobby, extras, onClose})` (`#uiSettings`): Sound on/off, Music, Effects (+ the arcade hum on the lobby), Motion, Mic sensitivity (store.sens, `Pitch.setSensitivity`) + the live meter (`Pitch.meterLevel()`, read even while paused; only when a mic is open), then each `UI.settings.register(fn(box), {title, lobby})` group (the game's own options; the lobby's Backup / Install); opened by the top bar's Settings button (`Sfx.mountControls(el, {lobby})`), the pause menu and the lobby; every value is saved on the device and shared by every game. MOTION = `gameData('bg').motion` (the old moving-backgrounds switch): off = still backgrounds and avatars AND `html.no-motion` (ui-kit.css ends every CSS animation/transition at once); scripts check `Arcade.reducedMotion.matches` (shared/version.js: the device's reduce-motion OR the switch; `addEventListener('change')`, `refresh()`), never their own matchMedia. INTRO `UI.intro.show({theme, hero, kicker, title, text, extra, go: {label, onClick}, back: {label, onClick}, onShow})` (`#intro`, `#introGo` = `[data-act=go]`). CONFIRM `UI.confirm({title, text, yes, no, danger, extra, theme, onYes(panel)})` → Promise<bool> (`#uiConfirm`; the safe answer has the focus; Esc = no); `UI.notice({title, text, ok})`; never `alert()`/`confirm()`. TOAST `UI.toast(text, {near, kind, ms})` (always above every panel). PANELS ON TOP (`UI.layer`, ui-kit.js): a panel opened from another panel must never open behind it: `UI.layer.open(el, {min, trap, onEsc, focus})` gives `el` an inline z-index = max(its own, `min`, the highest visible fixed/absolute child of body + 1), remembers the focus, and with `trap` adds the kit's Tab trap + Esc (only the TOP layer reacts) + `body.ui-modal`; `UI.layer.close(el)` clears it and puts the focus back on the opener. Every kit panel (confirm, notice, intro, pause, settings) goes through it, so a confirmation always lands above what asked it; so do Backup / Restore (min 80: above Settings 70 and the leaderboard 70, below confirmations 90 and toasts 95), Create Your Player, the Locker, Sustain Speedway's garage, the lobby's event panel and the app's panels. Never change a panel's look for it; `UI.layer.state()` for tests (tests/backup-layer.spec.js). Every kit panel: role dialog + label, focus in and back out, Tab trapped, Esc, ↑/↓/←/→ between a menu's buttons, keys never reach the game underneath, `body.ui-modal` while one is open (Arcade Quest's keys stop). `UI.state()` for tests.

## Hold guard

- HOLD GUARD (`Arcade.holdGuard(el, {lock, touch})`, ui.js; `.hold-guard` / `.hold-lock` in theme.css): every on-screen control that is HELD or tapped fast (Arcade Quest's pad and game area, Button Masher's fingering diagram, Note Ninja's answer pad; Chime Heist's kit, Dojo Duel and AnswerPad already had the same CSS) never selects text, shows the iPad callout/magnifier, flashes a tap highlight, or (`lock`) scrolls/zooms: no selection/callout/highlight CSS, contextmenu/selectstart/dragstart blocked, `lock` = `touch-action: none`, `touch` = a non-passive touchstart preventDefault (only where every control uses pointer events). Put no selectable text in such buttons (SVG icons, CSS content, aria-labels). Use it for any new held control.

## Overlays

- OVERLAYS SCROLL THEMSELVES: theme.css `.overlay` is the scroll container (`overflow-y: auto`, `overscroll-behavior: contain`, `touch-action: pan-y`, iOS momentum); its panel is centered by auto margins and starts at the top when taller than the screen. Never give an overlay's panel `max-height` + `overflow: hidden`, and never let it be cut off: let the overlay scroll. For a long overlay that must keep the page behind still, call `Arcade.lockScroll(true)` on open and `lockScroll(false)` on close (ui.js). Arcade Quest's `.q-panel` scrolls inside the game screen (`touch-action: pan-y` because `#stage` takes over touch).
