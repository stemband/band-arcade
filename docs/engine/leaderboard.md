# The leaderboard

- THE LEADERBOARD (`shared/leaderboard-config.js` + `shared/leaderboard.js`, loaded after seasons.js on every page that saves progress; `leaderboard-screen.js` on the floor, the top bar's trophy `#lbBtn`; `.lb-*` in arcade.css; README "Leaderboard & privacy"): Mat's Apps Script scoreboard. API: GET `?action=status` → `{ok, enabled}`; GET `?action=board&grade=6|7|8` → `{ok, enabled, grade, week, updated, boards: {stars, improved, streak, endless: {<gameId>: [...]}}}`, entries `{id (6 chars), name: [t, a, n], value}`; POST (Content-Type text/plain: no CORS preflight) `{pid, grade, name, game, type, value, level}`. fetch with `credentials: 'omit'`, redirects followed (Apps Script → googleusercontent), SIMPLE CORS REQUESTS ONLY (no preflight: Apps Script can't answer one): GET with no headers, POST with only `Content-Type: text/plain`, and NO `cache` option (WebKit has turned a non-default cache mode into Cache-Control/Pragma request headers); never blocks a game. A COLD SCRIPT can take 10–20 s: `Leaderboard.TIMEOUTS` = {read: 25000, send: 20000} ms, a board read that times out is tried ONCE more; WARM-UP `Leaderboard.warm()` = one quiet `?action=status` (result ignored, never in ?demo, at most once in 10 minutes: sessionStorage `bandarcade.lb-warm`), called by arcade.js when the floor opens, when the lobby shows and when the page comes back on screen on the lobby. THE LAST GOOD BOARD of each grade is kept in localStorage `bandarcade.lb-last` (not progress, not in the Backup Code): a failed read returns it `{ok, data, stale: true, at, why}`. `Leaderboard.lastRequest()` = `{ok, why ('timeout after 25 s' | 'offline' | 'HTTP 500' | 'not JSON' | 'network error (CORS or blocked)'), ms, tries, at, action}` (warm-ups don't count). EVENTS (storage.js calls them): `stars` = a level's best stars INCREASE (setLevel), `endless` = the score at game over when it beats this device's best this week for that game (addEndless), `play` = once a day (noteActivity with `play`). A QUEUE on the device (≤ 50, oldest dropped), sent one at a time, a failed/offline one retried (online, visible again, every 60 s); a refused one is dropped. Saved in `gameData('leaderboard')` (in the Arcade Backup Code): `{pid (24 × [a-z0-9]), grade, on (default true), queue, day, week, weekStars, endless, id (the device's 6-char id when the scoreboard returns one)}`. THE SCREEN: first open asks the grade (6/7/8, changeable in MY SETTINGS with the switch "Show me on the leaderboard" + "Only your avatar name and scores are shared. Never your real name."); grade switch (other grades viewable); tabs STARS THIS WEEK / MOST IMPROVED / PRACTICE STREAK / ENDLESS (+ game picker, `Leaderboard.ENDLESS_GAMES`); top 10 with #1–3 gold/silver/bronze, the device's own entry highlighted (`isMe`), else "You: 12 stars this week. Keep going!" from this device's numbers; "Resets every Monday · Updated a minute ago"; boards cached 60 s (sessionStorage); while a board loads: "Loading the leaderboard…" (`.ui-msg.loading` = the UI kit's spinner, `.lb-loading`), never the break message; a failed read with a saved board = that board + "Couldn't refresh — showing the board from 2 hours ago" (`.lb-stale`); nothing saved (or disabled) = "Leaderboard is taking a break. Your progress is still saved!". `?teacher` shows each entry's 6-character id (Mat blocks a player in the Sheet's Blocked tab) and under the board how the last request went (`.lb-diag`: "Last request failed: timeout after 25 s (took 50.1 s, tried twice)."). Tests: tests/leaderboard.spec.js (warm-up, simple requests, a slow board, the retry + saved board, the break message). NAMES ARE WORD NUMBERS: `Avatar.nameNumbers(av)` / `nameFromNumbers([t, a, n])` (unknown, retired or NEVER-USE = "Mystery"), `wordNumber`, `wordAt`; the numbers = each word's place (from 1) in avatar-names.js's APPEND-ONLY lists (a retired word is `'#Word'`: its number stays reserved); avatar-code.js's TABLE reads the same lists, so share codes use the same numbers (old codes decode unchanged). `Arcade.Leaderboard` (`available/settings/setGrade/setOn/canSend/board/mine/queue/flush`) and `Arcade.LeaderboardScreen.state()` for tests.
