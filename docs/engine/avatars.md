# Avatars, portraits, skins and the Locker

## Portraits

- Portraits (`shared/portraits.js`, loaded by every page with a top bar and by Select Player): the drawn fallback is `Arcade.portraitSVG(memberId, {size: 'big'|'tile'|'chip', color, glow, style: 'neon'|'line', cls, label})`, neon line art on a 100 × 100 grid built from parts (`tube` centerlines drawn as two glowing edges, `shape` outlines, `line`s, `ring`s); each instrument's signature color is a `--pt-<id>` token in theme.css. Color and style are options so a skin can restyle them; never hard-code a color in a part. The same drawing is used big, on tiles and in the chip.

## Portrait images and skins

- PORTRAIT IMAGES (Mat's artwork, `shared/portraits/`, mapping + how-to in its README.md): show a player's portrait ONLY with `Arcade.portraitHTML(memberId, {size, full, skin, label, cls, color})`, never an `<img>` of your own. It returns a square `.pt-box` (theme.css) with the SVG portrait underneath and the image on top, hidden until it loads; a missing or broken file tries the next candidate (`optimized/<name>.webp` if listed in `OPTIMIZED`, `<name>.png`, `<name>.webp`) and ends on the SVG, so a broken image never shows. `full: true` (the Select Player preview only) tries `<name>-full` first. `skin` ({color, acc}; left out = the instrument's equipped skin, `false` = none) draws the SKINS below and tries the drawn variants `<name>--<color>` / `<name>--<acc>` (and `-full--`) first; failed variant/-full URLs are remembered per tab in sessionStorage. `color` (recolored CPU rivals) or `'cpu'` = SVG only, no skin. File names are in `FILES` in portraits.js (member id → file name). Images are `object-fit: contain` on transparent backgrounds; markers (1P/2P) and outlines sit above them (`z-index`). An image over 250 KB or 1024 px gets a WebP copy in `shared/portraits/optimized/` (≤ 512 px; ≤ 1024 px tall for `-full`) listed in `OPTIMIZED`; the original is never touched, and replacing it means deleting its copy.
- SKINS (`shared/skins.js`, loaded right after portraits.js by EVERY page that shows a portrait; those pages also load `games.js`, which `allStars` needs for `byMember` games): one color skin + one accessory per instrument MEMBER, saved on the device (`store.skin(m)` / `setSkin(m, patch)`; shown ones in `store.skinsSeen(key)` / `markSkinsSeen`, key = member for star milestones, `'*'` for achievements). `Arcade.Skins`: `LIST` (the `SKINS` table: `{id (never change), kind 'color'|'acc', name, unlock, look | art}`), `ANCHORS` (accessory positions per instrument: `img`/`svg`/optional `full` × `head [x,y,w]`, `face [x,y,w,tilt]`, optional `back [x,y,w]`, all in percent of the square portrait; mirrored as a table in shared/portraits/README.md), `ACC_ART`, `isUnlocked(skin, member)`, `requirement(skin)`, `progress(skin, member)`, `milestone(skin)`, `equipped(member)` (a locked choice falls back to Classic Neon / none), `equip(member, {color}|{acc})`, `label(eq)` (alt text: "Trumpet, Flame skin, Crown"), `fresh(member)`, `announce(panel, {members, member})`, `catchUp(member)`, `refresh(member)`, `decorate()` (portraits.js's hook). UNLOCK RULES: `{always}`, `{stars: n}` = `store.allStars(member)` ≥ n (per instrument), `{game, level, stars, text}` = `store.bestLevelStars(game, level)` (any progress key of that game, any instrument) ≥ stars (`suffix: ':extra'` = only keys ending in it), `{game, badge: true}` = any Ancient Ninja Scrolls badge, `{game, achievement: id}` = `store.gameData(game).achievements[id]` (Sustain Speedway's `'virtuoso-win'`; Arcade Quest's `'ep1'` → Pixel Hero and `'manor-friends'` → Baton, set by `Q.save.achievements()`); achievements unlock for every instrument; a rule for a game missing from games.js is skipped. Rules are checked from saved progress (never only at the moment of a result), so old progress counts. EVERY RESULTS SCREEN calls `A.Skins.announce(panel)` after it shows (Chime Heist: `{members: ['bells'], member: 'bells'}`; Neon Face-Off: vs CPU only; the scrolls' Belt Exam badge panel too); Select Player calls `catchUp(store.player)` on load. Never show an UNLOCKED! card during play. Effects: CSS in theme.css "Skins" (`.sk-*`), drawn parts (flame aura, sparkles) in skins.js; tokens only; animation ONLY on `.pt-box-big` and never under reduced motion; image effects only once the picture loaded (`.pt-ok`), the SVG fallback just recolors (`svgColor`/`svgGlow`); a drawn variant sets `.pt-var-c` (effects off) / `.pt-var-a` (overlay off); Pixel redraws the loaded picture into a small canvas (`.pt-pix`). Portrait CSS must never style `.pt-box svg` descendants (the accessory is an `svg` too): use `.pt-box>svg.portrait`. `?demo&unlockall` previews everything (never saved, never announced).
