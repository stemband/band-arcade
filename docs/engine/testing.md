# Testing

- **Every PR must pass the tests.** New games must pass the smoke and game-run tests; add a tests/games.js entry if the game needs special steps.
- THE AUTOMATIC TESTS (`tests/`, README there; `.github/workflows/tests.yml` runs them on every pull request and push to main, Chromium + WebKit): SMOKE (`smoke.spec.js`: every page in `pages.js` at iPad landscape/portrait and Chromebook sizes: no JS/console error, no missing local file (except the optional files the site probes for: `OPTIONAL` in helpers.js), no outside host, no visible button off the screen sideways), GAME RUNS (`game-runs.spec.js` + `games.js`: every game in shared/games.js from ?demo Level 1 to its results with stars saved, Endless cards to GAME OVER; a game needing other steps gets a STEPS entry), PITCH (`pitch.spec.js`, Chromium: synthesized clarinet/flute/sax/trumpet/tuba tones through `Pitch._analyse`, octave-exact), NETWORK (`network.spec.js`: the leaderboard mocked, only the allowed fields, nothing in ?demo), SAVE (`save.spec.js`: the Arcade Backup Code round trip), AVATAR ITEMS (`avatar-items.spec.js`: old Quest codes v1–v3 read exactly as before, a v4 round trip, the Tumblers and the Grandmaster's Aura) SHOWTIME SNARE (`showtime-snare.spec.js`: every snare job with `Onsets.fake(time, level)`, fairness at every showtime) TUNE UP (`tuneup.spec.js`: the tabs and the mic per tab, the balloon's height/words/arrows, written vs concert names, HOLD IT, the tips, HEAR THE NOTE with the mic paused + TARGET mode, the snare's tab, the metronome's schedule/accents/6-8/subdivisions/tap/tempo words/silent mode/the bop on the audible beat/reduced motion/hidden tab, the Tempo Ladder on downbeats + HOLD + STEP BACK + the goal, the two items) SOUNDS (`sounds.spec.js`: every file in shared/sounds/ decodes in the browser; one the compressor processed is within 30 ms of its upload's length in `fixtures/sound-durations.json` (.m4a 0.1 s; the open-source Chromium has no AAC, so .m4a is decoded in WebKit) and a music loop's first/last 20 ms still sound; plus tests.yml's `sounds` job: `tools/compress-sounds.py --check` and `--verify` with ffmpeg, see [sound.md](sound.md)) SAVE YOUR PROGRESS (`backup-nudge.spec.js`, `?demo&nostart&today=`: no nudge with 0 stars, under the thresholds, in a game, on PRESS START, in pick mode or right after saving; nudges at `stars` new stars, `days` progress days, a new player's `firstAfterStars`, a break day and the school day before; Not now's snooze; `maxPerWeek`; Copy saves, only opening the panel doesn't; SAVE TO FILE's .txt; restoring that file = typing the code; a restore counts as saved; the iPad Home Screen tip; layout at phone/iPad/Chromebook; reduced motion) TODAY'S PRACTICE (`practice.spec.js`, `?demo&nostart&today=`: the plan per date/member, the override, the weekly skill rotation and the daily PLAY rotation, fallbacks only for instruments that suit none of a skill's games (every member × skill × 6 weeks), the same plan on two devices, `rotationStart` shifting the cycle, a kept day's plan, an old-style skill list, the weekend's weakest game, no repeats and every step suiting every member, the three warm-ups, a finished round vs. only opening a game, the practice level pick, one HOLD IT ring, 2 minutes of metronome on `page.clock`, the bonus paid once across reloads and two tabs, the week across a boundary, PRACTICE PRO, the card hidden without an instrument and its layout at phone/iPad/Chromebook sizes, reduced motion, a Backup Code restore) and RHYTHM DOJO (`rhythm-dojo.spec.js`: every Counting Board example, synthesized claps found to the millisecond, the game's own clicks looped back into the clap detector never counting, judging/rests/holds/feedback colors, the timing check, HEAR IT and pause). Run them: `cd tests && npm ci && npx playwright install chromium webkit && npx playwright test`.
- `python3 -m http.server` from the repo root, then open `http://localhost:8000/?demo`.
- Before finishing a change, verify with `?demo` that a level can be completed and that the arcade floor's HI-SCORE for that game updates (it shows only when an instrument is saved).
- `?demo` in the mic games (any NOTES pool) and the Note Checker's scale/chromatic modes: hold Space to play the note on the staff / the glowing note.
- Real-instrument testing is Mat's job. Ask him which instruments/notes misread rather than guessing at detector changes.

## Demo mode

- `Arcade.DEMO` is true with `?demo`. Keys 1–5 fake the five notes, and games should unlock all levels.

## Docs
- DOCS (`docs.spec.js`): CLAUDE.md ≤ 25 KB, a `docs/games/<id>.md` for every game in `shared/games.js`, every file in `docs/engine/` and `docs/games/` listed in CLAUDE.md's index, no broken links between the doc files. A new game or system gets its doc file and an index row in the same change.
