Run them: `cd tests && npm ci && npx playwright install chromium webkit && npx playwright test`.
- WAITS ON A BUSY RUNNER: a CI runner can be several times slower than a laptop, and a loaded WebKit can starve a page's animation frames for seconds. A test never waits a fixed time for something a game does over its frames (wait for the thing itself, as Blocktave's Pearl and loot waits do), a `waitForFunction` for something that ends on a TIMER (a Blocktave card closing) re-checks on a timer (`polling: 100`), not on the page's frames (Playwright's default), and a demo answer hook never loops until done (Blocktave's note cards answer each note at most once). Blocktave's 20-seed chapter 1 tests open EACH SEED IN ITS OWN BROWSER CONTEXT (WebKit's page process crashed on a busy runner after a few worlds in one page, taking every later seed with it), print each seed's page-process memory (`helpers.js pageMemory()`, Linux: loaded, after 5 Tone Ore, at the end) and, when a seed fails, the page's longest frame gap and any hidden / pagehide. A DIAGNOSTIC test (it only prints) plays 5 worlds in one page and prints the memory after each: growing world after world = memory Blocktave keeps between worlds; about flat = the runner.
- `python3 -m http.server` from the repo root, then open `http://localhost:8000/?demo`.
- Before finishing a change, verify with `?demo` that a level can be completed and that the arcade floor's HI-SCORE for that game updates (it shows only when an instrument is saved).
- `?demo` in the mic games (any NOTES pool) and the Note Checker's scale/chromatic modes: hold Space to play the note on the staff / the glowing note.
- Real-instrument testing is Mat's job. Ask him which instruments/notes misread rather than guessing at detector changes.

## Demo mode

- `Arcade.DEMO` is true with `?demo`. Keys 1–5 fake the five notes, and games should unlock all levels.

## Docs
- DOCS (`docs.spec.js`): CLAUDE.md ≤ 25 KB, a `docs/games/<id>.md` for every game in `shared/games.js`, every file in `docs/engine/` and `docs/games/` listed in CLAUDE.md's index, no broken links between the doc files. A new game or system gets its doc file and an index row in the same change.
