# Patterns and echo

- PATTERNS (`shared/patterns.js`, Lost Signal + Vanishing Ink; loaded after mode-picker.js): THE pattern generator: short melodies from the NOTES × ORDER note set, moving by steps, small skips, larger skips. `Arcade.patterns.noteSet(pickerState, pool)` → `{set (one item per SOUNDING pitch, low to high, items as buildSequence makes them), sig, fit, name}` (pool 3 = the smaller level-1 pool, 5 = all); `generate(set, len, {leap, repeats}, gen)` (leap = biggest skip in half steps: 2 steps, 4 thirds, 7 fifths, 12 octave; repeats = twice in a row allowed, never three; rules with skips always have one in 3+ notes); `next(set, pattern, rules, gen)` (one more note: the endless modes grow a pattern); `GEN` = the default weights (step, third, fourth, fifth, wide, octave, repeat, recover, noBigInARow, noPingPong, mustSkip); a game passes its own (`SIGNAL_GEN`, `INK_GEN` in its levels.js; missing fields use GEN). Never write a pattern loop in a game.
- ECHO (`shared/echo.js`, Lost Signal + Vanishing Ink; after patterns.js): THE echo flow. `Arcade.Echo.create({slots, slotHTML, timer, slotMs, running(), answering(), pauseSuppressed, sounds: {ok, bad}, onFill(i, r), onDone(res), onMark(item)})` → `echo` with `begin(pattern)` (draws one `.slot` per note), `start()` (answering starts, or restarts the current slot's clock), `fill(pc)` (the note heard fills the next slot right or wrong, `null` = missed; plays the tiny ok/bad sound), `mark()`, `pulse(i)`, `want()`, `i`, `res` ([{pc, ok}]); its own 100 ms slot clock (paused while the tab is hidden, and while `Pitch.isSuppressed` with `pauseSuppressed`; Lost Signal leaves that off because its mic is paused for its sounds). `Echo.input({enabled(), onNote(pc, time)})` = the note input: each `Pitch.onAttack` with a pitch, and an `onHeld` note no attack was heard for within 700 ms (soft entries: a long note is ONE note, a repeat needs a new attack); `.reset()` per pattern. `Echo.drawResult(el, {clef, pattern, res, sig, fit, name, gap, minW, label, idPrefix, plain})` = the pattern on a staff in written pitch, centered after the clef + key signature: right gold, wrong coral + "you played D", missed coral in a dotted box; `plain: true` = the same layout with no names or marks (Vanishing Ink's scroll while studying, so the ink comes back in the same place). Styles (`.slot.cur/.ok/.bad/.miss/.rx`) are each game's.
