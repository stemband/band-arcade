# Press Start and the level select pattern

- PRESS START (`shared/press-start.js`, `Arcade.PressStart.show(gameId, onStart)`; `.ps-*` in theme.css; loaded with `cabinets.js` + `marquees.js` after backgrounds.js by the 12 games): mountTopbar shows it ONCE per page load (never between a game's own screens): the game's marquee big (`Marquee.animate(el, 'title')`), over its menu background (`html.ps-on` hides the page except `#topbar`, which stays usable above the screen at `--ps-top`), "PRESS START" blinking slowly (1.1 s, soft; steady with reduced motion), "Tap anywhere or press any key", the game's stars (or its `summary`). The tap (pointerdown on the screen, or any key except Tab/Shift/Ctrl/Alt/Meta/Esc and keys on a top-bar button) runs after sfx.js's unlock in the same gesture: `Sfx.preloadScreen('game', 'general', <id>, 'endless')` (primes every effect), `eventSoon('press-start-<id>')` (falls back to `press-start`), the menu music (already wished for by the first screen; else `gameMenuMusic`), then a 0.4 s fade into the first screen already drawn underneath (`html.ps-reveal`). SKIPPED: `?nostart` (`?demo` still shows it), `Sfx.autoStart(300)` true (the browser already allows sound), a Back-button restore with the sound running. It never touches the microphone (requireMic at level start, as before). Arcade Quest (`pressStart: false`) keeps its own title; the Note Checker (a tool) has none. `PressStart.state()` for tests.
- THE LEVEL SELECT PATTERN (`shared/level-select.js`, loaded after press-start.js by every game; `.ls-*` in theme.css): SELECT, THEN START, like the note-set picker. `Arcade.LevelSelect.show({screen, grid, cards, unlocked(i), picker, endless, lockText(i), label(i), gameId, fresh, beside})` (`heading` = the cards' heading instead of "Select your level" (+ `need`: START's line until one is selected; `voice: false` drops the "Select your level" voice line): the Rudiment Trainer's "Select your rudiment" over its 40 rudiment cards (its family tabs only hide cards; the pattern's arrow keys skip hidden ones); `beside` = an element placed immediately LEFT of START in the sticky heading row, as tall as START, `.ls-beside`; on phones START still takes the rest of the line and never wraps; Tab reaches it before START; Sustain Speedway's GARAGE), called every time a game draws its level cards (i 0-based). HEADINGS: "① SELECT YOUR NOTES" (put at the top of the `picker`) and "② SELECT YOUR LEVEL" (no number without a picker) share ONE class, `.ls-head` (the announcer's neon lettering at section size, one line). The level heading sits in `.ls-row` with the START area (sticky at the top while the cards scroll under it). A tap/Enter/Space on a card SELECTS it (`.ls-sel`, `aria-pressed`: the chosen note set's look + a ✓; never starts the game: a capture-phase click listener on the grid stops the game's own handler); a locked card (`.ls-locked`, `aria-disabled`, the game's `disabled` removed so it can say so) shows `lockText` ("Clear Level N to unlock"; games say Vault/Belt/Showtime/Rival/Track) as a toast; the Endless tile (`endless` = its element) is selectable too ('endless'). Once a level is selected: START (`.ls-start`, "LEVEL 4 · FIRST FIVE": `label(i)` or the card's `.n` text + the picker's note set, "· SCALE ORDER" when it is) slides in with `start-ready`; before that "Select your notes and level" (`.ls-need`). START (tap/Enter/Space) re-clicks that card (or the Endless tile's `.ed-go`) with the listener standing aside, so it runs the game's own handler exactly as a tap used to (requireMic, story panels, intro screens). A new note set keeps the level and updates the line. REMEMBERED: `gameData('level-select')['<game>|<player>|<instId>']` = the index or 'endless', saved on selection and by `Arcade.LevelSelect.played(i)`, which every game's start function calls (START, NEXT LEVEL, RETRY), so the screen comes back with the level just played; restored when the screen appears (nothing if it's locked now or gone); first visit = nothing selected. THE SCREEN APPEARING (the first call, or the first after the screen was hidden: a MutationObserver) waits for PRESS START's tap, then: the `select-level` voice line ("Select your level"; `Sfx.announce`: at most once a minute, sessionStorage `bandarcade.select-level-at`, only after a tap started the audio, held while an overlay is open, music ducked), the focus on START when it's ready, and after `IDLE_MS` 5 s with no tap or key the IDLE HINT (`.ls-hint`, a bouncing arrow) at what's missing: the level cards when none is selected, else START (never a particular level); any tap/key hides it, and it comes back only for the next missing step. No recommended level, no glow on any card. `LevelSelect.highlight({screen, el})` = a setup screen's main button (Dojo Duel's BEGIN THE DUEL, Neon Face-Off's START MATCH, Arcade Quest's CONTINUE/NEW GAME): lit (`.ls-main`), focus, idle hint; no heading or voice. LAYOUT: picker, then the half-size note staff (`.ls-notes` wraps `#modePick` + `.fivecard.ls-mini`; ≥ 700 px wide the staff sits beside the picker's ORDER row and line, where it was before, so it adds no height), then the heading row + the cards, extras below, so both headings, START and the first row of cards fit without scrolling on an iPad and at 1366 × 768. `LevelSelect.state()` = `{sel, ready, hint, hintAt, appeared, summary}` for tests.
